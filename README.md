# 极简简历 MiniWho

**把履历写清楚，比堆满一页更有力量。**

极简简历 MiniWho 是一个可自部署的开源在线简历工作台。它用结构化模块代替花哨排版，让你专注在「做了什么、怎么做的、结果如何」；同时提供 12 套 A4 实时模板、可导出导入的模板包、证件照上传、服务端 PDF 导出、可控的分享链接和基于固定规则的简历诊断。

前端 Vue 3 + Element Plus，后端 Java 17 + Spring Boot 3 + Sa-Token + MyBatis-Plus，默认 SQLite、可选 MySQL 8。**全部功能免费，无会员、无付费模板、无外部 AI 调用。**

品牌域名：**[who.minims.cn](https://who.minims.cn)**（官方演示站；若暂时打不开，说明演示实例未开放，按下面的快速开始自建即可）

## 名字的含义

**Mini** 是最小可用的意思：一个单页、可自部署、没有会员体系的小工具，只保留「把履历说清楚」真正必需的部分。

**Who** 是你是谁——简历的本质就是回答这个问题。名字合起来是 **用最小的篇幅回答「我是谁」**：不靠花哨排版和堆砌形容词，让每段经历自己说话。品牌域名 `who.minims.cn` 取的也是这个 Who。

所以 Mini 不是「简陋」，而是克制：去掉多余的装饰，把注意力还给内容本身。

## 功能

### 简历编辑

- 18 种结构化模块：基本信息、求职意向、教育背景、工作经历、项目经历、在校经历、个人技能、技能熟练度、论文发表、作品集、自我评价、考研信息、竞赛经历、获奖情况、资格证书、论文期刊、兴趣爱好、自定义模块。
- 模块可排序、显示 / 隐藏、重命名；基本信息与教育背景不可隐藏。
- 单模块独立保存，服务端使用 `contentVersion` 乐观锁，避免多标签页互相覆盖。
- 本地草稿恢复：刷新或意外关闭页面后，可恢复尚未保存的修改。
- 富文本描述、月份区间、标签输入、URL 校验；服务端使用 jsoup 白名单清洗 HTML。
- 附件简历：最多 3 个，支持 jpg / jpeg / png / pdf / doc / docx / txt，单文件 10MB，带文件头校验。
- 简历照片：独立头像通道，工作台内裁剪（证件照 / 圆形两种版式），服务端解码校验后降采样到 600px 以内并重编码，单张不超过 3MB。
- 条目 LOGO：教育背景与工作经历的条目可各挂一张院校 / 公司 logo，独立通道不占附件额度，压到长边 256px 以内重编码；「金石」会把它排进版面，同模块内没上传的条目自动留出同样宽的占位栏位，不会错位。
- 内置一份完整的虚构示例简历，方便快速体验。
- 首页与模板中心展示的示例简历全站共用一份，由管理员把工作台上任意一份简历标为「首页示例」，不登录时回落到随代码打包的出厂示例。
- 预览里的证件照按示例简历的「性别」挑随代码打包的静态照片（男 / 女各一张，性别留空或「不公开」时回落首字徽标），不走真实头像通道，所以十几张缩略图不会出现签名链接过期的情况。

### 模板与导出

- 12 套原创 A4 模板：青禾、墨线、侧影、城市、简雅、秋叶、技术、学术、晨星、启航、青瓦、金石。
- 单栏、双栏、色带、居中、时间轴、头像单栏、经典、通栏照片侧栏、页眉证件照、标签式页眉、斜切色带旗标等不同版式，均有独立排版逻辑。
- 12 套都在页眉留了照片位（秋叶的证件照在姓名左侧，其余按各自版式摆放）；未上传照片时会自动回落到姓名首字徽标，不会留白。
- 纸面滤镜（原色 / 暖纸 / 黑白）、字号与行距微调、页脚品牌标识开关。
- **服务端 PDF 导出**：由本机 Chrome / Edge 无头打印渲染同一套 A4 版面，结果按内容与样式版本缓存 24 小时；检测不到浏览器时前端自动回落到「浏览器打印 → 另存为 PDF」，功能不中断。
- 预览即所得，打印时自动恢复 210 × 297mm 物理尺寸，可直接「打印 → 另存为 PDF」。
- **多页分页所见即所得**：内容超过一页时，纸面按 A4 高度实算断点并画出虚线与「第 N 页 · 共 M 页」标签；屏幕虚线、浏览器打印、服务端 PDF 用的是同一批断点标记，续页自动补齐页边距。双栏模板的正文列与侧栏列共用同一条页边界（落刀点必须同时是两列的空隙），侧栏底色铺满每一页。
- 样式自动保存；切换模板不影响简历内容。
- **模板包（可分享、可备份）**：每套模板——包括上面 12 套官方的——都以一个 JSON 模板包的形式存在，可以一键导出、发给别人、在别人（或自己）的部署里导入。导入后与官方模板完全同权：可预览、可切页、可导出 PDF、分页规则一致。
- 模板包只表达「主题 token + 一段受约束的 CSS」。CSS 在服务端逐条规则重新生成后才注入页面：选择器强制限定在该模板的作用域类下，`<`、`@import`、`expression()`、`behavior`、`!important`、外链 `url()` 一律拒绝；**格式里根本没有 HTML 与 JS 的位置**，所以社区模板不可能拿到执行能力或改坏别人的简历。
- 导入校验一次返回全部不合规原因；同命名空间重复导入即升级该模板，正在使用的简历跟着换新版式，PDF 缓存自动失效。
- **「我的模板」页是模板包的唯一操作区**（`/my-templates`）：导入、导出、删除，以及两个开关——分享到模板中心、允许他人导出模板包。模板中心与预览页都不提供导入入口。
- **站内分享**：分享到模板中心后，本站所有用户（含访客）都能在「社区模板」组里选用；导出权限关掉时别人只能选用、不能下载包，服务端对非作者返回 403，前端只把按钮换成「仅可使用」。取消分享不会破坏别人已经在用的简历。
- 自己写模板包请看 [模板包格式](docs/模板包格式.md)。

### 分享

- 生成高熵随机分享链接，可设置 4–20 位访问密码。
- 可选有效期（1–365 天或永久）、是否允许打印 / 下载。
- 手机号、邮箱、城市、个人主页等字段可隐藏；**隐藏字段在服务端被移除，不会发送到访客浏览器**。
- 支持查看次数、随时撤销；重新创建链接会使旧链接立即失效。
- 分享页同样渲染简历照片，照片链接是带 HMAC 签名的短时效地址，无法被猜测或长期转发。
- 分享页提供独立品牌页头、有效期提示与隐私说明。

### 简历诊断

- 五维规则评分：完整度 25 分、岗位匹配 25 分、表达质量 20 分、成果量化 15 分、格式规范 15 分。
- 输出总分、等级（优秀 / 良好 / 待提升 / 需打磨）、维度明细与最多 12 条可执行建议。
- 建议按优先级排序，可直接跳转到对应模块修改。
- 内容更新后提示报告已过期，支持一键重新诊断；结果可复现，不依赖外部 AI。

### 账号与管理

- 用户名 / 密码注册登录，BCrypt 密码哈希，Sa-Token 会话令牌。
- 个人中心：昵称、邮箱、修改密码、简历统计。
- 管理后台：运营概览、用户列表与冻结 / 恢复、模板启停、一键导出全部官方模板包（部署迁移备份）、首页示例简历设置、意见反馈回复。
- 用户反馈入口：登录后可在个人中心提交反馈，管理员在后台查看与处理。

### 工程与安全

- 默认 SQLite 零配置启动，一条 `SPRING_PROFILES_ACTIVE=mysql` 切换 MySQL 8。
- 后端统一响应信封、参数校验、全局异常处理。
- 上传文件扩展名 + MIME + 文件头校验，路径穿越防护，预览响应附 `nosniff` 与 CSP `sandbox`。
- 头像走独立通道：仅接收真实 JPEG / PNG 像素流，解码后统一重编码落盘，原始文件不保留；读取使用 HMAC 签名 + 6 小时时效的媒体链接，密钥由 `MINIWHO_MEDIA_SECRET` 提供。
- 条目 LOGO 走独立通道：同样只接收真实像素流并重编码，文件名是 128 位随机 UUID，读取链接不带签名但不可枚举；未被简历内容引用且超过 10 分钟宽限期的文件在内容落库时由服务端回收，删除简历清空整个目录。
- 服务端 PDF 只渲染本机无头浏览器访问自身的导出地址，导出票据 5 分钟过期且一次性绑定模板与样式。
- 服务端内容清洗与长度 / 数量限制；单份简历最多 30 个模块、单模块 20 条内容。
- 导入模板包的 CSS 由服务端逐条规则重新生成后注入：选择器强制限定在该模板的作用域类下，属性名走白名单，`url()` 只接受 `data:`，`<`、`@import`、`expression()`、`behavior`、`-moz-binding`、`!important` 直接拒绝；模板包格式本身不给 HTML / JS 留任何入口。
- 分享密码 BCrypt 存储，公开接口失败码区分「需要密码 / 密码错误 / 已过期 / 已撤销」。
- Docker Compose 一键部署：MySQL 8 + 后端 + Nginx 前端，数据与上传持久化。
- 所有页面响应式适配，打印样式独立处理。

## 快速开始

### 环境要求

- JDK 17+
- Maven 3.8+
- Node.js 18+（推荐 20 / 22）
- 可选：Docker 24+ 与 Docker Compose v2

### 1. 启动后端（SQLite 零配置）

```bash
cd backend
mvn spring-boot:run
```

首次启动会自动：

- 创建 `backend/miniwho.db` 与 `backend/uploads/`；
- 初始化 12 套模板（从 `backend/src/main/resources/template-packages/` 的模板包读入）；
- 创建演示账号与一份示例简历（可通过环境变量关闭）。

后端地址：`http://localhost:8080`，健康检查：`GET /api/health`。

> 服务端 PDF 导出需要本机存在 Chrome / Edge / Chromium 可执行文件。桌面环境一般已具备；容器或无桌面的服务器请按[部署指南](docs/部署指南.md)安装 chromium，否则导出接口返回 `PDF_ENGINE_UNAVAILABLE`，前端会自动回落到浏览器打印。

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173`。开发模式下 Vite 会将 `/api` 代理到 `http://localhost:8080`。

### 3. 登录体验

| 账号 | 密码 | 说明 |
| --- | --- | --- |
| `demo` | `demo123` | 普通用户，附带完整示例简历 |
| `admin` | `admin123` | 管理员，可进入 `/admin` |

> 以上账号仅用于本地演示。公开部署前请修改密码，或设置 `MINIWHO_SEED_DEMO=false` 并自行创建管理员。

### Docker Compose 一键启动（MySQL 8）

```bash
cp .env.example .env
# 编辑 .env，至少修改 MYSQL_ROOT_PASSWORD、DB_PASSWORD、MINIWHO_ADMIN_PASSWORD
docker compose up -d --build
```

访问 `http://localhost:8088`。前端页面与 API 打在**同一个镜像**里（前端产物随 jar 发布），对外只暴露一个端口；MySQL 仍是独立服务。

详细参数、数据备份、升级与反向代理配置见 [部署指南](docs/部署指南.md)。

## 数据与隐私

- 简历正文以 JSON 存储在 `resumes.content`，模块偏好与样式分别存储。
- 简历照片独立存储于 `uploads/avatars/{简历 ID}/`，只保留服务端重编码后的版本；更换形状不会重新上传图片，删除头像或删除简历会一并清理磁盘文件。
- 删除简历会同时清理该简历的附件记录与磁盘文件、诊断报告记录，并撤销有效分享链接。
- 分享页按白名单移除隐藏字段后返回，前端无法还原被隐藏的手机号或邮箱。
- 评分在服务端本地计算，不调用第三方 AI 或分析服务。
- 附件默认保存在本地磁盘；容器部署使用 named volume。
- 项目不包含广告或第三方统计脚本。页脚的访问次数与在线人数由本项目自己统计：只用一个前端本地生成的随机访客 id 去重与心跳，不采集 IP、UA 或浏览行为，也不会发往任何外部服务。
- 演示数据均为虚构，请勿在公开实例中填写真实身份证号等敏感信息。

## 已知边界与路线图

当前版本聚焦「可运行、可自部署、可验证」的完整 MVP，以下能力暂未实现：

- 服务端 Word / Markdown 导出：PDF 已由无头浏览器生成，Word 与 Markdown 导出在路线图中。
- 简历导入解析 / OCR：暂不支持上传旧简历自动识别。
- AI 润色与岗位匹配：诊断完全基于固定规则，结果可解释、可复现。
- 30+ 模板与集中式模板市场：当前 12 套官方模板全部免费，模板包机制已支持导出、导入与本站内分享（作者可选是否允许他人下载包）；还没有的是跨部署的中央市场（搜索、评分、精选位与人工审核），以及社区模板的异步试渲染校验。
- 模板骨架与 token 的彻底解耦：版式的 DOM 结构与分页契约目前仍由代码持有（这是分页一致性的前提），模板包只能改 token 与作用域 CSS。
- 版本历史、协同编辑、短信 / 微信登录、邮件找回密码。
- 对象存储：默认本地文件系统，横向扩容前建议接入 S3 / OSS。
